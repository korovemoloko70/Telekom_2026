# telekom_hw3

Файловый сервер на TCP-сокетах (C, POSIX) с клиентом на C. ## Идея

Базовый сервер из гайда Beej обслуживает одного клиента за раз: `accept()` →
обработка → `close()`. У меня сделано сверх этого:

1. **Несколько клиентов одновременно** — через `select()` + `fork()`.
2. **Свой прикладной протокол** поверх TCP — с заголовками, кодами ответа и
   разделением файлов по длине, а не по `\n`.
3. **Пакетная команда `GETM`** — несколько файлов одним запросом, при этом
   ошибка по одному файлу не обрывает остальные.

## Возможности

- `GET <файл>` — скачать один файл.
- `GETM f1 f2 f3` — скачать несколько файлов одним запросом. (`GETM` проверяется раньше `GET`. Иначе `GETM a b` распарсится как `GET` файла `M a b` — классическая ловушка префиксного парсинга. Порядок `if` в парсере критичен.)
- Несколько одновременных соединений (`select` + `fork`).
- Защита от path traversal (`..`) — нельзя вылезти за пределы `server_files/`.
